# v1.5.0 — 适配 Codex 26.1111

适配 Windows Codex `26.1111.21308`（MSIX `26.1111.2228.0`，内置 CLI
`0.169.0-alpha.11.1`）。新版仍会在不带 `Retry-After` 的 HTTP 429 后结束回合，
本工具继续接手 app-server 已明确放弃的可重试错误。

## 修复内容

- 补齐 `flexUnavailable`、`inferenceHookDenied`、`tooManyDenials` 三个新版错误。
  Flex 资源不足默认无限重试、至少间隔 30 秒，保留原服务层级；两类明确拒绝不重试。
- GUI、CLI、热换工具统一核对实际运行的脚本版本。旧脚本显示需要重新注入；
  页面重载时可替换先运行的旧版本，停止后的排队重试不会继续发送。
- 修复原窗口关闭后新窗口无法自动补注入的问题，并实现 CLI 的 `--watch` 持续注入。
  页面重载后缺失的脚本可恢复，单个新窗口注入失败不会阻塞其他新窗口。
- 备用 ASAR 补丁按 renderer 文件边界配对倒计时数组与 getter，支持变化的压缩变量名、
  多个副本、中断后的补齐与逐字节还原；歧义或不相关代码会拒绝修改。
- 发布流程增加真实协议覆盖检查、注入升级测试、备用补丁自检及 EXE 内嵌完整源码核验。
  同时发布 `SHA256SUMS.txt`，便于核对下载文件。

## 验证范围

决策、请求构造、分片消息及完整自动重试回放测试通过；新版真实协议的 23 个错误全部覆盖，
并保留 3 个旧版错误。9 项 Python 注入与 CLI 测试、GUI、备用补丁及打包 EXE 自检通过。

真实 Codex 的只读 IPC、6 MB 分片读取与请求协议检查通过。备用补丁对当前安装包成功识别
两个 renderer 副本，共四处等长替换位置；本次未写入安装包。
真实故障后的生产重试未单独触发，完整自动重试由隔离回放验证。
详见[兼容性报告](https://github.com/fujunchao/codex-never-give-up/blob/v1.5.0/docs/compatibility-26.1111.21308.md)。

## 升级方法

下载并替换 `codex-never-give-up.exe`，打开后点击“重新注入”。已有调试端口时可直接热换；
否则注入器需要重启 Codex 以启用调试端口。

源码用户在项目目录执行 `python tools/hotswap.py`。升级后脚本版本应为
`2026-11-15.codex-26.1111-v1`，IPC 分类数为 26，CFG 规则数为 17。
